Ironbark Electrical - three themes

All three use the same screens, data and layout. Only the design tokens and a few theme details change, so whichever theme is picked can be applied through the CSS variables in app/globals.css. Every page has a dark or light mode switch (moon button), the invoices page can show its loading, empty and error states, and My day can show the offline state.

Harbour

Calm, light, corporate

Harbour blue on cool white, set in Public Sans. The four headline numbers sit in one ruled panel so they read as a single statement, not four separate tiles. It is the safest choice for prospects from any industry and sits closest to the console as it is now.

Ironbark

Warm, sturdy, made for the trade

Taken from the business name: dark ironbark timber for the sidebar, a pale gum-leaf background and hi-vis yellow for the things that need attention. Job numbers look like cable labels. Barlow Condensed fits long dollar amounts into narrow tiles and reads well on a phone in bright sun.

Switchboard

Dark first, modern

Deep blue-slate rather than black, with status shown as small indicator lights, like on a real switchboard. It looks sharp in a pitch and is easy on the eyes in a van before sunrise. Its light mode keeps the dark sidebar. It is harder to read outdoors at midday, so technicians would want the light mode.

Recommendation: Ironbark

It is the only one of the three that is clearly about this business. A prospect sees a branded product, not a generic admin panel, and that is the point the demo has to make. The hi-vis accent does a real job too: it appears only on things that need attention, so the dashboard reads at a glance. It also holds up best on a technician's phone outdoors.

Harbour is the fallback, and a good default for the M-Street kit itself, so other businesses start neutral and add their own brand on top.
