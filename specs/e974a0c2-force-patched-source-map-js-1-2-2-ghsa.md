# Force patched source-map-js 1.2.2 (GHSA-68fv-2mgg-jv7q)

**Type:** feature

Automated security maintenance (IT-1034). source-map-js 1.2.1 is a transitive dependency (via postcss, @tailwindcss/node and source-map-loader), not listed in package.json. Add one override in pnpm-workspace.yaml forcing ^1.2.2, the version the scanner names as fixed for GHSA-68fv-2mgg-jv7q (event-loop DoS via indexed source-map section offsets). App behaviour does not change. The lockfile must be regenerated with `pnpm install`; it is not hand-edited.

## Acceptance criteria

- **AC-1** Given pnpm-workspace.yaml, when the change is applied, then `overrides:` contains `'source-map-js@<1.2.2': ^1.2.2` with a comment naming what brings it in (postcss, @tailwindcss/node, source-map-loader) and GHSA-68fv-2mgg-jv7q, in the style of the existing entries.
- **AC-2** Given the change, then package.json is unchanged (source-map-js is not a direct dependency) and no other entry in pnpm-workspace.yaml is altered.
- **AC-3** Given `pnpm install` is run to regenerate pnpm-lock.yaml, then every source-map-js entry resolves to 1.2.2 (or higher within ^1.2.2) and none resolves to 1.2.1. The lockfile is not hand-written in this change.
- **AC-4** Given the updated lockfile, when the CI verify job runs (migrate, lint, typecheck, test, build), then all steps pass with no edits to tests or application code.
- **AC-5** Given an osv scan of the regenerated lockfile, then GHSA-68fv-2mgg-jv7q is no longer reported for source-map-js. Both listed findings are the same advisory and are cleared by 1.2.2.

## Edge cases

- If pnpm's minimumReleaseAge policy blocks 1.2.2 at install time, a reviewer must decide whether to add an exclusion; this spec does not add one.
- Both scanner findings are the same advisory ID (GHSA-68fv-2mgg-jv7q), so 1.2.2 clears all of them.

## Out of scope

- Any application code, tests, or business rule changes
- Changes to package.json
- Adding source-map-js to minimumReleaseAgeExclude (only if install is blocked by the release-age policy; a reviewer can add it then)
- Upgrading postcss, tailwind or source-map-loader
- Hand-editing pnpm-lock.yaml

## Affected areas

- pnpm-workspace.yaml (overrides)
- pnpm-lock.yaml (regenerated by pnpm install, not hand-edited)
